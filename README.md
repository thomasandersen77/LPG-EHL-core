# LPG-EHL Workspace

This repository is a **workspace container**.

- **Main application**: `projects/lpg-ehl/` (Maven multi-module + React frontend)
- **Other projects/tools**: `projects/`
- **Legacy/reference material**: `legacy/`

## Main project entrypoint

```bash
cd projects/lpg-ehl
./build_monolith.sh
```

Project docs live in `projects/lpg-ehl/docs/`. Start with `projects/lpg-ehl/README.md`.
