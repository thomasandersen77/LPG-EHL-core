# Terminal - LPG-EHL Payment Terminal Integration

Dette er en komplett samling av all kunnskap og kode relatert til terminal-integrasjonen i LPG-EHL prosjektet.

## Innhold

### markdown/
Alle Markdown-dokumenter relatert til:
- Terminal-testing og bruk
- ECR Server setup
- Betalingsflyt
- Implementeringsguider

### scripts/
Shell-skript for:
- Kjøring av ECR server
- Testing av terminal
- Nettverks-scanning
- Demo-programmer

### kotlin/
Payment-relaterte Kotlin-filer:
- NetsBaxProtocol.kt - BAX protokoll implementasjon
- EcrServer.kt - ECR server implementasjon
- PaymentTerminal.kt - Terminal integrasjon
- Demo og test filer

### config/
Konfigurasjonsfiler for terminal og testing

### docker/
Docker-relaterte filer for multi-station setup
